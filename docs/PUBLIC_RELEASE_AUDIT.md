# Public release audit

Prepared on 7 October 2026. This independent source repository was created from
the cleaned and tested prototype working tree, at the owner's request. It starts
with a new initial commit; the original Git database, branches and remotes were
not copied. No ZIP/archive or GitHub publication was created. License and asset
redistribution decisions remain open.

## Removed

26 existing files were removed, totaling 66,124,090 bytes (about 63.06 MiB):

- Eight background audio files: five music themes and three continuous ambience loops.
- Ten reproducible blueprint exports: five SVGs and their five PNG copies.
  The exporter and its README remain; generated outputs are now ignored.
- Four screenshots from the superseded isometric implementation and one old
  movement diagnostic JSON capture. Historical explanations remain without broken
  screenshot links.
- One unreferenced Town South editor draft. The canonical layout and map editor remain.
- The obsolete lane-browser smoke script, replaced by the current polygon smoke check.
- The Lucy extraction utility, whose expected source sheets no longer exist and
  whose individual-frame output is no longer consumed by the renderer.

## Music cleanup

The entire `assets/audio/music/` working-tree folder was removed. It contained:

- `title/title-theme.mp3`
- `battle/battle-theme.mp3`
- `forest/forest-theme.mp3` and `forest/forest-ambience.wav`
- `deep-forest/deep-forest-theme.wav` and `deep-forest/deep-forest-ambience.wav`
- `town/town-theme.mp3` and `town/town-ambience.wav`

Title, map and battle playback calls, the music resolver, track/ambience mappings,
fades and restart hooks, map soundtrack assignments, preload entries and the Music
Volume control were removed. The nonexistent optional boss track hook was removed
as well. Documentation and affected tests now describe the SFX-only release.

The unused `settings.musicVolume` save field is deliberately retained for compatibility
with older saves. It contains no resource reference and no longer affects playback.

## Preserved

All thirteen SFX are byte-for-byte unchanged, verified with SHA-256 comparisons:
weapon whoosh/impact; fireball, ice, poison and poison tick; guard; UI tab/confirm;
encounter; victory/defeat cues; dialogue typewriter audio. The fireball MP3 remains
because it is a gameplay sound effect. All audio resources left in the working tree
are under `assets/audio/sfx/`.

Gameplay source, sprites, backgrounds, effects, UI art, map geometry, the map editor,
fallback/reference artwork, regression tests and useful development notes remain.
Repeated Highwayman animation files are retained because their authored filenames
are generated by animation metadata. Uncertain asset candidates were kept.

A small existing runnability defect was fixed: the Deep Forest → Front Forest
arrival was outside walkable ground. Its image-space arrival moved from
`(1340, 635)` to `(1340, 700)`, within the existing walkable contour and outside the
return trigger. No walkable polygons, exits, combat rules or game features were
added. The geometry fixture records that corrected arrival.

## Security / privacy

Pattern scans found no obvious API/provider keys, quoted credential assignments,
private-key blocks, authenticated URLs, `.env`/credential files, personal contact
details in current project files, machine-specific absolute paths, private IPs or
private endpoints. No credential was discovered or removed.

Current PNG metadata and printable audio metadata were inspected in addition to
source/configuration files. Signed image-provenance certificate information is
preserved; it does not establish asset licensing rights. Loopback URLs in preview
tools and instructions are intentional local-server addresses, not private services.

`.gitignore` now excludes local editor files, logs, dependencies, build/export
directories, generated blueprints, browser/test output, temporary audit output,
environment overrides and common key/credential file extensions. Source assets
and example environment files are not ignored.

These are pattern-based checks, not a guarantee that all possible sensitive data
can be identified. Git identity metadata is addressed separately below.

This repository has a fresh initial commit containing only the sanitized source.
The original repository's 669 commits, backup branches, tags, remotes and reflogs
were not copied. Historical music/ambience and the original personal author email
are therefore absent from this repository's Git history.

original 669-commit history, with no obvious historical credentials or private
paths found. Those original objects are not part of this repository.

## Validation

- Baseline: 169/169 syntax checks and 34/36 test files passed. Two files exposed
  the same pre-existing Deep Forest return-arrival defect.
- Final `node scripts/run-checks.mjs`: 169/169 syntax checks and 36/36 test files
  passed after audio cleanup and the arrival correction. No tests were skipped.
- Static resource audit: 494 import, HTML/CSS, literal asset and preload references
  checked; 91 unique preload assets; no missing resources. All three remaining
  project JSON files parse successfully. No Godot configuration exists: this is a
  plain browser JavaScript project.
- Media/file audit: exactly thirteen audio files remain, all SFX; all thirteen
  hashes match their originals. No music assets, archives or old executable/build
  packages remain in the release working tree.
- Headless Edge launch and `node scripts/browser-smoke.cjs`: title/settings,
  New Game, keyboard movement, equipment/inventory and skill menus, F2 inspection,
  all four maps, all six real warp transitions and walkable arrivals, battle
  entry/escape/return, autosave/Continue, and decoding all thirteen SFX passed.
  No game warnings, uncaught page errors, missing resources or unexpected failed
  local requests were observed. Browser-cancelled media requests are accepted only
  when the same resource independently decodes successfully.
- External font requests were deliberately blocked to verify system-font fallbacks.
  Live Google Fonts availability and exact online typography were not verified.
- Combat settlement/return used the existing escape outcome API. The browser check
  is a smoke test, not a full manual playthrough; combat behavior and rewards are
  covered by the existing Node regression suite. Audible sound quality was not
  assessed; browser decoding was verified.
- The copied source was verified by SHA-256 before README/audit updates.
- Final whitespace, music-reference and security checks were performed. Temporary
  validation captures and helper files were removed after recording these results.
